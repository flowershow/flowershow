---
title: Getting Started — From the Terminal (CLI)
description: Publish any folder of markdown from the terminal. No repo required.
---

1. Install (macOS / Linux): `curl -fsSL https://raw.githubusercontent.com/flowershow/flowershow/main/apps/cli/install.sh | sh`. On Windows, see [[reference/cli#installation|installation]].
2. Log in: `fl login`
3. Publish: `fl ./my-folder` (Markdown, HTML, or both)
4. Update later: `fl ./my-folder`

See [[reference/cli|CLI reference]] for all commands and options.
